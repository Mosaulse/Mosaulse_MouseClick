# 开发约定

## 代码风格

- **语言**：Python 3.8+
- **编码**：UTF-8
- **缩进**：4 空格
- **命名**：snake_case（函数/变量）、PascalCase（类）

## 导入顺序

1. 标准库
2. 第三方库
3. 本地模块

## 注释规范

- 模块级：简要说明用途
- 类级：说明职责和使用方式
- 方法级：说明参数、返回值、异常
- 行内注释：解释复杂逻辑

## 测试规范

- 框架：pytest
- 命名：`test_<功能>.py`
- 函数：`test_<行为>()`
- 覆盖：核心业务逻辑（models/utils）

## Git 规范

- 分支：`main`（生产）、`develop`（开发）
- 提交：`[类型]: 描述`（中文）
- 类型：新增/修复/重构/测试/文档/样式/优化/发布/依赖

## 依赖管理

- 新增依赖前评估必要性
- 避免引入重型框架
- 系统级依赖使用延迟导入

## 错误处理

- 捕获具体异常，避免裸 `except`
- 记录错误日志
- 用户可见错误使用 `QMessageBox`

## 性能注意

- GUI 线程禁止阻塞操作
- 长时间任务使用线程
- 避免频繁 I/O（如设置保存无防抖）
